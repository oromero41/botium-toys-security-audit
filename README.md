# Botium Toys | Cybersecurity Audit Case Study

**Academic portfolio project | Google Cybersecurity Professional Certificate**

A structured, English-language case study based on the fictional *Botium Toys* training scenario. The project reviews security controls, highlights potential risk and compliance-related control gaps, and proposes a prioritized remediation roadmap.

## Areas reviewed

- Identity and access management, including least privilege and separation of duties
- Data protection, encryption and sensitive customer information
- Backup, disaster recovery and business resilience
- Intrusion detection and alerting
- Password policy and centralized credential management
- Asset inventory, data classification and compliance-related controls

## Deliverable

The [audit case study](Botium_Toys_Cybersecurity_Audit_Case_Study.pdf) includes an executive summary, seven prioritized findings/evidence notes, security control and compliance-checklist coverage, a proposed 90-day improvement roadmap, and a limitations and methodology section.

## Method and source material

The report draws on two course artifacts:

1. *Botium Toys: Scope, goals, and risk assessment report* — the provided training scenario.
2. *Controls and compliance checklist* — the completed academic assessment and recommendations.

A separate `tcpdump traffic log` exercise was **not** included in this project because it does not relate to the Botium Toys audit scenario.

The source scenario and assessment checklist contain differences (for example, around some integrity/privacy procedures and password controls). The report flags these as evidence to validate rather than presenting either document as automatically conclusive.

## Tools and competencies demonstrated

`Security Auditing` · `Risk Assessment` · `Security Controls` · `Access Control` · `PCI DSS` · `GDPR` · `Security Reporting`

This is a **documentation and analysis project**, not a live penetration test or hands-on validation of security systems.

## Portfolio disclosure

Botium Toys is a fictional educational scenario. Findings are derived from course-provided material and a completed training checklist; the proposed remediation plan is a portfolio recommendation. No real Botium Toys system was accessed, no production security controls were tested, and no independent compliance attestation is implied.
